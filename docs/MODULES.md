# 功能模組規格（共用說明書）

兩套店家系統（妍序 Skin、禾域 HEYU）的功能模組，以這份為準。每個模組有分類：

- 共用：所有店家都適用，兩邊做法一致。預約通知（通知個人 LINE）也歸共用：只要預約量大，不論有沒有多位老師都會想要。
- 臉部專屬：只有妍序有（皮膚紀錄）。
- 多位老師才需要：老師排班、分潤與月結算。妍序目前只有老闆一人所以用不到，但不是身體專屬，之後擴編就能用。
- 包堂：堂數包與扣堂。妍序目前不做，同樣不是身體專屬。

CRM 店家頁依分類分組顯示。每家店的系統只回報自己有的模組，所以只做某一邊的店家看不到另一邊專屬的項目。店家後台沒開通的模組整項隱藏，不顯示灰色項目。新模組一律預設關閉，只有 CRM 能開關。
