# 功能模組規格（共用說明書）

兩套店家系統（妍序 Skin、禾域 HEYU）的功能模組，以這份為準。每個模組有分類：

- 共用：臉部與身體店家都有，兩邊做法一致。
- 臉部專屬：只有妍序有。
- 身體專屬：只有禾域有。

CRM 店家頁依分類分組顯示。每家店的系統只回報自己有的模組，所以身體店家看不到臉部專屬項目，反之亦然。店家後台沒開通的模組整項隱藏，不顯示灰色項目。新模組一律預設關閉，只有 CRM 能開關。

| 功能 | 分類 | 妍序 key | 禾域 key | 說明 |
| --- | --- | --- | --- | --- |
| 營收數據 | 共用 | revenue | stats | 月營收、單日營收、明細 |
| 營收統計 | 共用 | revenueStats（需開營收數據） | stats | 依月份、年度、項目統計 |
| 每日收款對帳 | 共用 | reconcile | reconcile | 每筆實收與付款方式（可自訂）、單日對帳表 |
| 爽約記錄 | 共用 | noShow | noshow | 標記爽約、累計次數、歸零 |
| 爽約限制 | 共用 | noShowBlock（需開爽約記錄） | noshow | 達門檻擋客人自己預約，門檻由 CRM 設定 |
| 預約提醒 | 共用 | 內建 | reminders | |
| 客人自助預約管理 | 共用 | 內建 | selfService | |
| 開放預約月份 | 共用 | 內建 | monthOpen | |
| 日曆 | 共用 | 尚未做 | calendar | 單日時間軸 |
| 皮膚紀錄 | 臉部專屬 | skinRecord | 無 | 預約詳情內的皮膚狀態紀錄 |
| 老師排班、預約通知、分潤月結、包堂 | 身體專屬 | 無 | schedule、teacherNotify、commission、packages | |

新增或修改共用模組時，兩邊一起改，並更新這張表。
